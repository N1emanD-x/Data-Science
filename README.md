## ▶️ Cara Menjalankan Notebook

**Via Google Colab:**
1. Buka [colab.research.google.com](https://colab.research.google.com)
2. Pilih **File → Open notebook → GitHub**
3. Masukkan URL repository ini
4. Pilih notebook yang ingin dijalankan
5. Klik **Runtime → Run all**
